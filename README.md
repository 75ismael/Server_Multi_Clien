# 🎮 Mastermind TCP - Networking Project

Ce projet implémente un serveur **Mastermind multi-joueurs** utilisant des sockets TCP en Java. Il a été réalisé dans le cadre du cours de Réseaux (L3 Informatique).

## 🚀 Fonctionnalités

- **Communication TCP** : Protocole client-serveur robuste.
- **Multi-threading** : Gestion de plusieurs sessions de jeu simultanées.
- **Logique de Jeu** : Validation des tentatives, calcul des scores et synchronisation.

## 🛠 Tech Stack

- **Langage** : Java
- **Concepts** : Sockets TCP, Threads, Flux d'entrée/sortie (I/O).

## 📦 Installation & Exécution

1. Compilez les fichiers source :
   ```bash
   javac -d out src/*.java
   ```
2. Lancez le serveur :
   ```bash
   java -cp out Main
   ```
